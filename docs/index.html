cache-nudge

A Claude Code plugin that nudges you once before an idle session's prompt cache goes cold, then lets you choose what to do about it.

InstallGitHub

Why

Claude Code caches the conversation for an hour. While it is warm, each message reads the conversation at about a tenth of the input price; once it expires, the next message writes the whole conversation back at about twice the input price. On a 150k-token conversation that first message back costs as much as about 300k input tokens. When you are about to step away from a large session, it is worth a decision.

The band

Above the prompt, on the right: the countdown and the conversation's size. Quiet while there is time, amber in the last ten minutes, red once cold.

[more] or /nudge opens it: what the next message costs now and once cold, and the options for the time you will be away, with the cheapest marked.

Keep warmA tiny hidden request every 50 minutes for the hours you choose, so the cache never expires while you are away. It does not add to the conversation.
Then compactIf keep-warm runs out and you still have not typed, compact while the cache is warm, so coming back only costs the summary.
Ping onceOne hidden request now: one more hour of cache.
Write handoffClaude writes a handoff file while the cache is warm; /clear and start from it when you are back.
Compact nowClaude Code's own /compact, while summarising is cheapest.

Install

/plugin marketplace add pelayomendez/claude-cache-nudge
/plugin install cache-nudge@pelayomendez-cache-nudge

Requires Claude Code 2.1.287 or newer. Nothing runs on its own except the one nudge: keep-warm requests start only when you choose them, on your own session and account. Details, settings and the cost model in the README.
